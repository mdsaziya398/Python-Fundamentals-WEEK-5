# Python Fundamentals – Week 5: Object-Oriented Programming

## Objective

This project demonstrates the fundamental concepts of Object-Oriented Programming (OOP) in Python using simple real-world examples. It covers Classes and Objects, Constructors, Inheritance, Polymorphism, Encapsulation, and Abstraction.

## OOP Concepts Covered

Object-Oriented Programming is a programming approach that organizes programs using classes and objects. A class acts as a blueprint, while objects are instances of a class. Constructors (`__init__`) are used to initialize object attributes when objects are created.

Inheritance allows a child class to reuse the attributes and methods of a parent class. Polymorphism allows the same method name to perform different actions depending on the object. Encapsulation protects object data by using private or protected attributes and provides controlled access through methods. Abstraction hides unnecessary implementation details using abstract classes and abstract methods, allowing child classes to provide their own implementations.

The project includes practical Python programs demonstrating these concepts through examples such as students, employees, animals, and bank accounts.

## Files Included
